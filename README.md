# mi-rutina-coach-releases

Este repositorio **solo contiene artefactos compilados** de Mi Rutina Gym (coach): el APK de Android, el paquete web de actualización en vivo (zip), su manifiesto y sus `.sha256`.

- El código fuente es privado y no se publica aquí.
- Los releases los publica el dueño con el script `npm run release` del repo privado.
- Las apps instaladas leen `releases/latest/download/manifest-coach.json` para actualizarse solas.
- Nunca se borran releases publicados.
